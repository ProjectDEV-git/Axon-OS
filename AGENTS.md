# AGENTS.md — Axon OS

AI-native Linux distro (Ubuntu 24.04 + GNOME Shell 45+), Python/GTK. Other projects live in their own repos.

## Working style

- **Single agent by default.** Read the files you need and make the change yourself.
- Use the multi-agent pipeline (`explore → bug-hunter → bug-fixer → test-runner → code-reviewer`) only when the user explicitly runs `/qa-pipeline <path>`.
- Skills: `.mimocode/skills/<name>/SKILL.md` (`iso-build-test`, `new-service`).

## Keep out of the noise

- Don't read `apex-win/` unless the task is about Windows apps (Rust sandbox, vendored). Run `cargo clean` there if you're not building it.
- Never run `find` or `grep -r` from the repo root. Search a specific dir (`services/`, `apps/`, `tests/`) or use the code map below.
- Ignore `build/`, `screenshots/`, `po/`, `packaging/*/files/` unless the task is about them.

## Commands

- Lint / format: `ruff check apps/ services/ tests/ installer/` (`--fix`), `ruff format ...` (same paths)
- Typecheck: `mypy apps/ services/ --ignore-missing-imports`
- **Default test run:** `pytest tests/test_x.py -q --tb=short`
- Full coverage run (CI / pre-push only): `pytest tests/ -v --tb=short --cov=apps --cov=services --cov-report=term-missing --cov-fail-under=40`
- Everything: `bash scripts/qa.sh`. CI order: ruff → mypy → pytest (cov ≥ 40%) → bandit.
- Tests need Linux (dbus, GTK). Markers: `slow`, `integration`, `unit`; 30 s timeout per test.

## Conventions

- Line length 100, Python 3.10+, Google docstrings.
- `gi.require_version()` must precede `from gi.repository import ...` (E402 ignored).
- Service dirs use hyphens (`axon-brain/`); imports use underscores. `tests/conftest.py` aliases them.
- New D-Bus service: `services/<name>/`, subclass `ServiceBase` (`services/service_base.py`); see the `new-service` skill.
- Constants: `from services.constants import DBUS_NAME_BRAIN, AXON_DIR, OLLAMA_BASE_URL`.
- SQLite `with conn:` only commits/rolls back. It does NOT close. Call `conn.close()` or use the pool.
- No `curl | sh` in shipped code. Use apt, Flatpak, or a pinned URL + SHA-256.
- Docker: `docker compose up -d`; Ollama at `host.docker.internal:11434`; services use `Dockerfile.service`.
- ISO contents and size budgets: `docs/iso-policy.md`. Read it before adding any package.
- `kernel/axon-winabi/` is written but NOT compiled or tested yet.

| Dir | Owns |

| `axon-context/` | Window/clipboard/file context: `context_service.py`, `clipboard_store.py`, `file_indexer.py` |
| `axon-search/` | `search_service.py`, `global_search_service.py`, `indexer.py`, `rag.py` |
| `axon-voice/` | `advanced_voice_service.py`, `intent_router.py`, `overlay.py` |
| `axon-gaming/` | `gaming_service.py`, `catalog.py`/`catalog_installer.py` (catalog in `data/gaming/`), `gpu_drivers.py`, `game_mode.py`, `steam_games.py` |
| `axon-gui-agent/` | `gui_agent_service.py`, `plan.py` |
| `axon-sandbox/` | `sandbox_manager.py`, `shield.py`, `audit*.py` |

Apps (`apps/`, GTK; `main.py` is the entry point, `ui/` holds windows):

| Dir | App |
|---|---|
| `axon-ai-panel/` | AI side panel (`ui/panel.py`, `context_reader.py`) |
| `intent-bar/` | Intent bar (`ui/window.py`, `spaces_manager.py`, `ollama_client.py`) |
| `axon-settings/` | Settings (`preferences_window.py`, `ai_models.py`, `shell_settings.py`) |
| `axon-game-center/`, `axon-files/`, `axon-terminal/`, `axon-welcome/`, `axon-installer/`, `axon-voice-overlay/`, `axon-confirm/`, `axon-shortcuts/` | One app each |
| `shared/` | Design tokens (`axon-design-tokens*.css`), `axon_gtk_utils.py` |

Elsewhere:

- `shell/axon-shell/`: GNOME Shell extension (JS). JS tests are in `tests/js/`.
- `installer/`: installer backend (`installer/modules`, `partitioner.py`); UI is `apps/axon-installer/`. `system/`: updater and boot watchdog.
- `build/`, `scripts/`, `packaging/`: ISO build, helper scripts, `.deb` sources.
- `theme/`: GTK theme, icons, tokens (generated by `scripts/gen_tokens.py`).
- `data/`: desktop files, polkit, `gaming/catalog.json`.
- `docs/`: start with `architecture.md`. `DEVELOPING.md` has the dev setup.
- Tests: `tests/test_<module>.py` mirrors module names (e.g. `test_brain_service.py`).
